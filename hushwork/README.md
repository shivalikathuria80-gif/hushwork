# Hushwork

Standalone landing site. React 18 + Tailwind (CDN) + Lucide, no build step, no dependency on the design system.

Open `index.html`. Files: `ui.jsx` (Icon, Btn, Logo), `Hero.jsx`, `Sections.jsx` (how it works, folders, waitlist), `Features.jsx`, `AgentBox.jsx`, `Footer.jsx`, `Login.jsx`, `App.jsx` (sidebar, nav, routing).
