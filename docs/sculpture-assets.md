Recorded 2026-10-15. Read this before using the sculpture anywhere public.

## The component

- File: `hushwork-app/components/ui/liquid-sculpture-hero.tsx`
- Author: Guglielmo Giannattasio (https://guglielmogiannattasio.it), published on 21st.dev as `@gughigug/components/liquid-sculpture-hero` on 13 Oct 2026.
- Licence: **MIT**, as shown on the component's 21st.dev page (checked 2026-10-15). MIT lets us use and change the code if the copyright notice stays with it. The notice is in the file header; do not remove it.
- It needs no extra packages (no `three`, no `lucide-react`).
- Two lines were repaired after a copy-paste broke them (a raw line break inside the default headline and inside the headline splitter). Nothing else was changed.
- The file is excluded from lint on purpose (`hushwork-app/eslint.config.mjs`) because it is third-party code.
- The component shows a small "by guglielmogiannattasio.it" credit link by default (`showCredit`). Keeping it is the courteous choice.
