## The four images (ours)

The four images in `hushwork-app/public/sculpture/` are generated by `hushwork-app/scripts/make-sculpture.mjs` in this repository on 2026-10-16. No third-party image, model or asset was used. Copyright the Hushwork owner; all rights reserved unless the owner states a licence.

| File | Pixels | Flat background | What it is |
|---|---|---|---|
| `light.webp` | 1983 x 793 | `#eeecf2` | landscape, light theme |
| `dark.webp` | 1983 x 793 | `#0c0a10` | landscape, dark theme |
| `mobile-light.webp` | 1024 x 1300 | `#eeecf2` | portrait, light theme |
| `mobile-dark.webp` | 1024 x 1300 | `#0c0a10` | portrait, dark theme |

What they show: one continuous ribbon of brushed, folded metal in the Arjun AI purple scale. It enters from the left as dust, folds over itself into one open ring, and dissolves into dust on the right. Light and dark pictures use the same shape and the same random seed; only the colours differ. Colours come only from the Arjun purple ramp plus two grey neutrals per theme (`scripts/sculpture-config.json`).

### Why the background must be one exact colour

The sculpture component finds the form by its colour: every pixel within a few levels of the background colour is treated as empty. So each picture has one flat background colour, and that colour is also the colour of the panel behind it (`--sunken` in `app/globals.css`, `PANEL` in `components/login/SculpturePanel.js`). Then the picture has no visible rectangle, in the live version or in the still version.

### How to change or re-make them

Run these inside `hushwork-app`:

```bash
npm run make:sculpture
```

Draws the four images (about 15 seconds) and writes them into `public/sculpture/`. Same input, same bytes: it uses a fixed seed, no clock and no `Math.random`.

```bash
npm run make:sculpture -- --verify
```

Draws them again in memory and fails if a file on disk differs, or if any rule below is broken.

```bash
npm run make:sculpture -- --out some-folder --png
```

Writes the pictures (and PNG copies you can open) somewhere else, to look at a change without touching the site.

```bash
npm test
```

Runs every test, including `lib/sculpture.test.js`: file sizes, budget, flat border, and that the background colour is the same in the config, the CSS and `SculpturePanel.js`.

Rules the script checks (numbers live in `scripts/sculpture-config.json`):

- every file is at most 250,000 bytes; it is saved lossless first, and near-lossless is used only if that is over budget and the border still equals the background exactly
- the outer 32 pixels are exactly the background colour
- every pixel fully inside the form is at least 0.08 away from the background, so the component never turns it into a hole
- every colour in the form sits on the palette; the form covers about 10 to 45 percent of the picture; the form keeps empty margins; the particle count the component will make stays in a sensible range

The old placeholder pictures (beige and brass, from 21st.dev, licence unknown) are no longer used. They remain in git history (commit `f72a1e3`), and that only matters if the repository is ever made public.
